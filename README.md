# VigilCode-AI 🛡️

**Autonomous AST Heuristic & Vulnerability Engine** | Zero-dependency static client-side security scanner.

## 🚀 Live Demo
You can access and use the live application here:
👉 [VigilCode-AI Live URL](https://vigilcode-ai.vercel.app)

## ✨ Features
* **Multi-Language Support:** Preset checks for JavaScript, Python, SQL Injection, AWS Keys, and XSS.
* **Autonomous AST Heuristic Analysis:** Real-time deep scanning to catch code vulnerabilities instantly.
* **Automated Scoring & Remediation:** Instant security grading with actionable auto-fix code suggestions.
* **Client-Side Security:** Zero backend dependencies, ensuring your code stays completely private and secure in your browser.

## 🛠️ How to Use
1. Open the live app link.
2. Select a language preset or paste your source code into the editor buffer.
3. Click scan to view real-time vulnerabilities and remediation guides.
